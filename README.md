# 카드뉴스 메이커

인스타그램 / 유튜브 커뮤니티 게시물을 가져와서 **유튜브 커뮤니티용 카드(1080x1080)와 본문 글**을 만들어 주는 윈도우 프로그램입니다.
원본 자막은 지우고, 글은 새로 써서, 검정 배경 + 초록 포인트 카드로 다시 그립니다.

## 설치

1. [최신 버전 받기](https://github.com/choi980103/cardnews-maker-releases/releases/latest) → `CardnewsMaker-x.x.x-win.zip`
2. 압축을 풀고 **카드뉴스메이커.exe** 실행
3. "Windows의 PC 보호" 창이 뜨면 → **추가 정보 → 실행** (서명 안 된 개인 프로그램이라 뜨는 안내입니다)

윈도우 10/11이면 따로 설치할 것이 없습니다. 자세한 사용법은 압축 폴더 안의 **사용설명서.txt** 를 보세요.

## 처음 한 번: Claude API 키

글을 쓰는 AI는 각자의 API 키로 동작합니다. 쓴 만큼만 결제됩니다.

1. [console.anthropic.com](https://console.anthropic.com) 가입 → Billing에서 크레딧 충전 (5달러면 200개 이상)
2. API Keys → Create Key → 키 복사
3. 프로그램 [설정] → API 키 붙여넣기 → 저장

| 모델 | 게시물 1개 | 40개 |
|---|---|---|
| Haiku 4.5 | 약 15원 | 약 600원 |
| Sonnet 5 (기본) | 약 30원 | 약 1,200원 |
| Opus 5 | 약 80원 | 약 3,200원 |

절약 모드를 켜면 30~40% 더 줄어듭니다. 목록 불러오기·카드 다시 그리기·수정·삭제는 무료입니다.

## 주요 기능

- **가져오기** — 유튜브 채널 주소, 인스타 @계정, 게시물 링크
- **자동 판단** — 사진 / 사연 / 글귀 / 짤을 구분해 각각 다른 방식으로 카드를 만듭니다
- **광고·영상·이미 만든 글 자동 제외**, 즐겨찾기, 모두 선택
- **매일 자동 만들기** — 정해진 시간에 새 글을 알아서 카드로
- **자동 업데이트** — 켜면 새 버전을 확인하고 버튼 한 번으로 설치

## 알아둘 점

- 공개 계정·채널만 가져올 수 있습니다.
- 자동 판단이 가끔 틀립니다. 올리기 전에 카드와 본문을 확인하세요.
- 남이 만든 사진과 글을 가져다 쓰는 것이므로, 저작권 문제는 각자 판단하고 책임져야 합니다.

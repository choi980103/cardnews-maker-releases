# 카드뉴스 메이커

인스타그램 / 유튜브 커뮤니티 게시물을 가져와 유튜브 커뮤니티용 카드(1080x1080)와 본문 글을 만들어 주는 윈도우 프로그램입니다.

## 설치
1. [Releases](https://github.com/choi980103/cardnews-maker-releases/releases/latest) 에서 최신 zip 을 받아 압축을 풉니다.
2. 폴더 안의 **카드뉴스메이커.exe** 를 실행합니다.
3. 처음 실행 시 "Windows의 PC 보호" 창이 뜨면 [추가 정보] → [실행] 을 누릅니다.

자세한 사용법은 압축 폴더 안의 **사용설명서.txt** 를 참고하세요.

## 업데이트
프로그램을 켜면 새 버전을 자동으로 확인합니다. 상단에 [업데이트] 버튼이 보이면 눌러주세요. 알아서 받아서 교체하고 다시 켜집니다.
